# letinder

Тиндер-like приложение, созданное в целях обучения vue3

Запускается через бот https://t.me/letinder_bot (можно написать что угодно и появится ссылка на открытие приложения). На кнопке дизлайка вызывается экран мэтча, для удобства отладки.

Через webapp tg api веб-приложение общается с тг, что позволяет менять ui телеги, получать тему пользователя, разворачивать приложение в фуллскрин, запускать нативные алерты и много чего еще.
